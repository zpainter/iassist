Utilizing Python For Analyzing Scholarly Open Access Usage Data

This presentation covers a Python data analysis project analyzing the use of Open Access Transformative Agreements by Vanderbilt University’s business school faculty. This project involves cross-referencing different data sets to determine: where target faculty are publishing, where they are publishing in relation to the specific journals in the open access transformative agreements, and what journals covered in these transformative agreements faculty may want to publish in based on journal impact factor. Participants will gain access to Python code via Google Colab with instructions on how to complete this project at their own university by replacing synthetic journal and author data with their own university data.
